Project 4 - GUI Program

This project was all GUI, and I didn't really know what to make. But I ultimately decided on a random hero picker
for overwatch. When you run it, a main window pops up with three options for the roles, either Tank, DPS, or Support.
Upon clicking one another window opens, and it only has a button that will get another random hero, and the text that shows what hero was chose


I didn't end up using the PIL or whatever it was, it was something for images but I couldn't get it to work. In fact, I couldn't get images

As of right now (04/23/2025) it will run fine when pushing F5 or the run button. The image stuff is commented out so it won't throw errors
